# Changelog

## 0.2.0 (2026-11-13)

- Repository moved to `hillocklabs/hillock`; install with
  `/plugin marketplace add hillocklabs/hillock`. Old links redirect.
- Two foundation skills in the router bundle: `neuro-file-formats` and
  `neuro-data-sources`.
- Tool references for EEG/MEG (MNE, EEGLAB, FieldTrip, Brainstorm), spike
  sorting (SpikeInterface, Kilosort 4, curation, Neuropixels), real time
  (LSL, BrainFlow, PsychoPy, Psychtoolbox, BCI2000, OpenViBE), stimulation
  (SimNIBS, ROAST, Percept, Lead-DBS, k-Wave, BabelBrain, NEURON, ASCENT)
  and devices (front-end chips, potentiostats, thermal, FDA databases,
  SBOMs).
- New scripts with tests: `inspect_recording.py`, `lsl_stream_check.py`,
  `percept_timedomain.py`, `tus_indices.py`, `fda_lookup.py`,
  `osv_check.py`.
- Continuous integration on Python 3.11 and 3.12, and structure tests for
  manifests, frontmatter and reference links.
- Logo, banner and gallery, each generated by a script in `brand/`.

## 0.1.0 (2026-11-12)

- First release: 30 skills in five bundles plus a router, six agents,
  eleven scripts and the 46-task benchmark.
